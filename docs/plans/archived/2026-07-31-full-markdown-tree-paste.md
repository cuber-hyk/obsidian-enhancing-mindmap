# 完整 Markdown 文档粘贴为节点树

## 目标

选中节点后粘贴包含标题、列表、普通段落和公式的完整 Markdown 文档，能够一次性生成层级正确、正文不丢失、公式可渲染的子节点树，并保持现有纯文本粘贴和内部节点复制行为。

## 范围

- 范围内：
  - 标题按标题级别建立层级。
  - 有序、无序列表按缩进建立层级。
  - 普通段落附加到最近的标题或列表节点正文，不额外制造节点。
  - 标题或列表前的前导普通内容合并为一个直属子节点，避免静默丢失。
  - 将围栏代码之外的 `\(...\)` 与独立 `\[...\]` 公式分别规范化为 `$...$` 与 `$$...$$`，保留现有 `$...$` 与 `$$...$$`。
  - 引用、围栏代码块和 Markdown 表格原样附加到最近节点正文。
  - 忽略正文中的水平分隔线；忽略文档开头的 YAML frontmatter。
  - 保持一次粘贴对应一次撤销/重做，并触发既有动态尺寸与布局刷新。
- 范围外：
  - 完整 CommonMark/Obsidian Markdown 语法解释器。
  - 将链接、图片、任务列表、脚注或 callout 转换成专用节点类型。
  - 改变 Obsidian/MathJax 对 `\(...\)`、`\[...\]` 的全局渲染规则。
  - 改造整篇脑图文档加载路径 `MindMapView.mdToData`。
  - 修改内部节点 JSON 复制格式或普通文本按行生成同级节点的规则。

- 范围明确：是；采用少量确定性规则，不追求完整 Markdown 解析。
- 事实来源已知：是；已检查剪贴板入口、现有解析器、Markmap 转换结果、节点渲染和布局刷新路径。

- 验证路径已知：是；生产构建、解析样例矩阵和测试 Vault 手动验证。

## 假设与决策

- “其中：”等普通段落附加到最近的结构节点正文；其后的顶层列表仍作为该结构节点的直接子节点。
- 文档包含标题或列表时视为结构化文档；完全不含结构标记时继续沿用“每个非空普通文本行生成一个同级节点”。
- 结构化文档中，正文块与最近结构节点使用空行拼接，以保留 Markdown 块边界。
- `\(...\)` 与独立 `\[` / `\]` 仅在围栏代码块外分别转换为 `$...$` 与 `$$`；行内公式会移除定界符内侧首尾空格，显示公式保持内部内容和换行，不替换代码中的普通反斜杠文本。
- 水平分隔线只作为分隔符忽略；位于文档开头且闭合的 YAML frontmatter 整块忽略。
- 内部节点 JSON 粘贴继续拥有最高优先级，Markdown 解析失败时不修改脑图。
- 本功能是确定性文本转换，不引入模型调用、第三方 Markdown 解析依赖或兼容双轨。

## 风险与控制

- 围栏代码、公式和表格包含类似标题或列表的字符：扫描时先锁定完整块，再识别结构行。
- 未闭合块导致数据误分层：检测到未闭合 frontmatter、围栏或显示公式时失败退出，不执行部分插入。
- Markmap 丢弃普通块或把表格展开为单元格：正文先替换为唯一占位标记，转换完成后按节点恢复，不直接把正文块交给 Markmap。
- 占位标记与用户文本冲突：每次解析使用不可预测的批次标识并校验所有标记均被恢复；不完整恢复视为解析失败。
- 规则扩张造成维护成本：只覆盖验收矩阵中的块类型，不增加完整 Markdown parser 或通用 `utils` 模块。

## 验收标准

- 用户给出的完整 Markdown 可粘贴，主要层级、普通正文和公式均不丢失。
- 纯文本、简单标题/列表、内部节点复制、撤销/重做和即时尺寸刷新无回归。
- 对无法安全解析的输入不插入部分节点，并保留剪贴板原文。
- `npm run build` 通过，测试 Vault 验收矩阵通过且控制台无新增异常。
